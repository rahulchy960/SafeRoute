# Third-party material in the Android app

What the app contains or is built with that SafeRoute did not write, and under which licence.
The licence names below were read on 2026-10-02 from each artifact's published POM (for the
foojay resolver, Gradle and the icon repository: from the project's GitHub licence). Update this
file in the same pull request that adds or removes a dependency or an asset.

## Icons

| Asset | Source | Licence | Changes |
| --- | --- | --- | --- |
| `res/drawable/ic_my_location.xml` | Material Symbols (Outlined) `my_location`, [google/material-design-icons](https://github.com/google/material-design-icons) | Apache-2.0 | header comment added, `tint` attribute removed |
| `res/drawable/ic_layers.xml` | Material Symbols (Outlined) `layers`, same repository | Apache-2.0 | header comment added, `tint` attribute removed |
| Search, Settings and Warning icons | `androidx.compose.material:material-icons-core` | Apache-2.0 | none (used from the library) |

`material-icons-extended` is not used: it adds thousands of icons to the build for the two we
need. Further icons are added one by one as vector drawables from Material Symbols.

## Launcher icon (placeholder)

`res/drawable/ic_launcher_*.xml` and `res/mipmap-*/ic_launcher*` were generated by Android
Studio's New Project wizard and show the Android robot. They are placeholders and will be
replaced by SafeRoute's own icon before release (Notion follow-up "App icon and splash
design"). Until then:

> The Android robot is reproduced or modified from work created and shared by Google and used
> according to terms described in the Creative Commons 3.0 Attribution License.

No other Google or Apple logo, font or artwork is in the app.
