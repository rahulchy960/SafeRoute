# Contributing

Thanks for your interest in SafeRoute Kolkata!

## Code contributions: not accepted yet

The project is **not accepting code contributions** (pull requests) at this time. Keeping a single
copyright holder keeps the licensing simple and leaves the option to relicense later. Pull requests
from outside the project will be closed without review, so please don't spend time on one.

If contributions open later, a **contributor agreement** will be required before any contribution
can be merged. This file will say so when that happens.

## Issues are welcome

You're welcome to open an issue for:

- **Bugs**: what you did, what you expected, what happened, and your device or environment.
- **Ideas and feedback** about the app, its safety features or the documentation.

Please don't put personal data in issues: no phone numbers, home addresses, exact locations of
people, or screenshots that show them.

## Security vulnerabilities

**Don't report vulnerabilities in a public issue.** Use GitHub private vulnerability reporting as
described in [`SECURITY.md`](SECURITY.md).
